Kebijakan Privasi

Terakhir diperbarui: 22 Oktober 2026.

Ringkasan

File yang Anda pilih di Kompak diproses di browser Anda sendiri dan tidak dikirim ke server kami. Kami tidak meminta Anda membuat akun dan tidak meminta data pribadi untuk memakai alat apa pun.

File Anda

Foto, PDF, dan dokumen yang Anda buka diproses di memori perangkat Anda. Hasilnya dibuat dan disimpan di perangkat Anda. Kompak tidak mengunggah, menyimpan, atau membaca file tersebut. Sandi yang Anda ketik untuk mengunci atau membuka PDF juga hanya dipakai di perangkat Anda.

Data yang disimpan di browser Anda

Kompak menyimpan sedikit data di browser Anda agar situs terasa nyaman:

  • Pilihan tema terang atau gelap.
  • Daftar alat yang terakhir Anda pakai.
  • Salinan halaman dan pustaka agar alat dasar bisa dipakai tanpa internet (cache service worker).

Data ini tetap di perangkat Anda dan bisa dihapus kapan saja lewat pengaturan browser, dengan menghapus data situs.

Iklan

Kompak dapat menampilkan iklan dari Google AdSense untuk membiayai situs ini. Google dan mitra iklannya dapat memakai cookie atau teknologi serupa untuk menayangkan dan mengukur iklan, termasuk iklan yang disesuaikan dengan minat Anda. Penjelasannya ada di cara Google menggunakan data dari situs mitra. Anda bisa mengatur atau mematikan iklan yang dipersonalisasi di pengaturan iklan Google. Iklan tidak pernah memiliki akses ke file yang Anda proses.

Log server

Situs ini dihosting di GitHub Pages. Seperti layanan hosting pada umumnya, penyedia hosting dapat mencatat data teknis standar seperti alamat IP dan jenis browser saat halaman dibuka. Kompak sendiri tidak menyimpan data tersebut.

Anak-anak

Kompak ditujukan untuk umum dan tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipasang di halaman ini dengan tanggal pembaruan di atas.
