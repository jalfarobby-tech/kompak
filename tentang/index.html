Tentang Kompak

Alat foto dan PDF yang cukup dibuka dan dipakai. Tanpa daftar, tanpa unggah.

Apa itu Kompak

Kompak adalah kumpulan alat untuk merapikan foto dan dokumen: kompres foto, ubah ukuran dan format, gabung dan pisah PDF, Word ke PDF, OCR, kunci PDF, tanda tangan, dan lainnya. Semua dibuat gratis dan bisa dipakai langsung dari browser di HP maupun laptop.

Mengapa dibuat

Banyak situs serupa meminta Anda mengunggah file ke server mereka. Untuk dokumen seperti ijazah, KTP, atau CV, itu bukan pilihan yang nyaman. Kompak dibuat agar file Anda tidak pernah meninggalkan perangkat.

Cara kerjanya

Setiap alat berjalan sebagai program di halaman web yang Anda buka. File dibaca dan diproses oleh browser Anda sendiri, lalu hasilnya Anda simpan. Tidak ada akun, dan tidak ada file yang dikirim ke server Kompak. Setelah dibuka sekali, alat dasar juga bisa dipakai tanpa internet.

Batasan yang jujur

  • Kecepatan bergantung pada perangkat Anda. File yang sangat besar bisa lambat di HP lama.
  • Word ke PDF dan PDF ke Word tidak sepresisi program desktop. Tabel dan tata letak rumit bisa berubah, dan PDF ke Word hanya mengambil teks.
  • PDF ke Excel dan PDF ke PowerPoint belum tersedia, karena hasil yang rapi butuh mesin khusus yang tidak bisa dijalankan di browser.
  • Kunci PDF melindungi file dengan sandi. Gunakan sandi yang kuat dan simpan sendiri, karena sandi yang hilang tidak bisa dipulihkan.

Siapa di baliknya

Kompak dibuat dan dirawat oleh Alfarobby di bawah ACP, Alfa Creative Project. Saran dan laporan masalah sangat membantu agar alatnya terus membaik.

Pustaka yang dipakai

Kompak memakai pustaka sumber terbuka yang dijalankan di perangkat Anda: pdf-lib, PDF.js, JSZip, mammoth, heic2any, Tesseract.js, dan QPDF. Lisensinya disertakan di folder situs.
