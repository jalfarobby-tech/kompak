KOMPAK - situs kompres foto dan olah PDF
Develop ACP — Alfa Creative Project by Alfarobby

Alamat situs di file ini: https://kompak.biz.id
Isi folder ini sudah lengkap, semua pustaka ada di folder vendor/ dan huruf di fonts/.

CARA UNGGAH KE GITHUB (tanpa Git)
 1. Ekstrak zip ini. Buka folder hasil ekstrak sampai terlihat index.html.
 2. Di GitHub, buka repo Kompak > Add file > Upload files.
 3. Tekan Ctrl+A di folder itu lalu SERET semuanya ke halaman GitHub (jangan pakai tombol "choose your files").
 4. Pastikan daftar file memuat jalur seperti vendor/pdf.min.js, lalu Commit.
 5. Settings > Pages: Custom domain = kompak.biz.id, centang Enforce HTTPS.
 6. Buka situs, tekan Ctrl+F5.

DAFTAR GOOGLE
 search.google.com/search-console > sitemap.xml > URL Inspection > Request Indexing untuk beranda.

PUSTAKA PIHAK KETIGA (lisensi ada di vendor/licenses/)
 pdf-lib, pdf.js, JSZip, mammoth.js, heic2any, tesseract.js, qpdf (WebAssembly, Apache-2.0), font Archivo.
