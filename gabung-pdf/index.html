Gabung PDF Online

Satukan beberapa file PDF menjadi satu dokumen. Urutan mengikuti daftar, atur dengan tombol panah.

Cara menggunakan

  1. Pilih dua file PDF atau lebih.
  2. Atur urutannya dengan tombol panah.
  3. Tekan Gabungkan dan simpan hasilnya.

Pertanyaan umum

Berapa banyak PDF yang bisa digabung?

Tidak ada batas tetap. Batasnya adalah memori perangkat Anda, jadi file yang sangat besar bisa terasa lambat di ponsel.

Bagaimana mengatur urutan gabungannya?

Gunakan tombol panah di daftar. PDF paling atas menjadi bagian pertama.
