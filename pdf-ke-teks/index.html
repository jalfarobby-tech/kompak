PDF ke teks Online

Salin seluruh teks dari PDF ke file .txt. PDF hasil scan (berupa gambar) tidak punya teks yang bisa diambil.

Cara menggunakan

  1. Pilih file PDF.
  2. Isi halaman yang ingin diambil, atau biarkan kosong untuk semua halaman.
  3. Tekan Ambil teks, lalu simpan file .txt.

Pertanyaan umum

Kenapa hasilnya kosong?

PDF hasil scan hanya berisi gambar, jadi tidak ada teks yang bisa diambil. Alat ini tidak melakukan OCR.

Apakah tata letak tabel ikut terjaga?

Tidak sepenuhnya. Teks diambil per baris, jadi tabel dan kolom bisa berantakan.
